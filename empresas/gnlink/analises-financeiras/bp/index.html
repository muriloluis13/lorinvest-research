Base histórica não carregada
Arraste o arquivo gnlink-bp-historico.xlsx aqui, ou clique para escolher.
O dashboard carrega a base automaticamente quando os arquivos gnlink-bp-historico.xlsx e gnlink-bp-historico.js estão na mesma pasta do HTML (o .js é o espelho que o navegador aceita ler via file://, no duplo-clique). Servindo por HTTP (ex.: python -m http.server) ele lê o próprio xlsx. Este seletor é só para carregar um arquivo de outra pasta.
